# Photos

Drop real photographs here using **exactly** these filenames (`.webp` preferred; `.avif`, `.jpg`, `.png` also work — only the base name has to match).
They are picked up automatically at build time. Any file that is missing falls back to its illustrated vintage placeholder, so the site never shows a broken image.

- Size: ~1600px on the long edge for `hero-campus`, ~1000–1200px for the rest. Aim for < 250 KB each.
- Aspect: 4:3 landscape works everywhere.
- Don't pre-apply heavy filters — the site already adds grain, dust, fade and light leaks.
- Use generated or licensed images only. No real celebrities or identifiable historical people.

Every prompt below starts with this style prefix:

> 1980s Indian film photograph, 35mm Kodak film, faded warm colours, film grain, dust, soft flash, slight light leak, candid, no text
